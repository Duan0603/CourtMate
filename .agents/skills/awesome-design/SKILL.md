# Awesome Design (DESIGN.md Collection)

This skill provides access to structured `DESIGN.md` files extracted from top-tier products and brand design systems.

## Available Design Systems
Check the folder `design-md/` in this skill for full design system specifications:
- **Linear (`design-md/linear.app/DESIGN.md`)**: Ultra-minimal, dark-first, precise desktop feel.
- **Vercel (`design-md/vercel/DESIGN.md`)**: Monochrome precision, high contrast, clean typography.
- **Stripe (`design-md/stripe/DESIGN.md`)**: Vibrant gradients, elegant typography, polished fintech aesthetic.
- **Apple (`design-md/apple/DESIGN.md`)**: Generous whitespace, clean SF Pro style hierarchy.
- **Supabase (`design-md/supabase/DESIGN.md`)**: Emerald dark theme, developer-first aesthetic.
- ...and 70+ more brand design specifications (Airbnb, Notion, Raycast, Expo, Claude, etc.).

## How to use
Refer to any `DESIGN.md` in `design-md/<brand-name>/` to inspect design tokens, component rules, color palettes, and typography guidance before implementing UI.
